# TempoStrike Android

Native Android app based on the current HITRISE feature set. It uses a distinct application ID (`com.zclei.tempostrike`) so it can be installed beside HITRISE. The cloud API base URL is `https://hitrise.86086.cn/tempostrike`.

Open this directory in Android Studio and build the `app` module. The source namespace remains `com.zclei.hitrise` for compatibility with the copied code; the installed app identity and visible app name are TempoStrike.
